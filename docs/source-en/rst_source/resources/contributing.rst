Contributing
============

Contribute bug reports, documentation fixes, or robot and planner integrations. See the repository’s `CONTRIBUTING.md <https://github.com/RLinf/RPent/blob/main/CONTRIBUTING.md>`_ for the workflow, code style, and required checks.

For documentation changes, follow the `documentation style guide <https://github.com/RLinf/RPent/blob/main/docs/STYLE_GUIDE.md>`_, update both languages, and build both with warnings treated as errors. State the actual validation scope for new features.

Extension guides: :doc:`../development/add_robot`, :doc:`../development/add_primitive`, and :doc:`../development/add_planner`.
